# The Design Quest · CESA × FOF

Landing page for the CESA × FOF designathon, built with React + Vite from the Figma design.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Config

- Event start date and registration link: `EVENT_START` / `REGISTER_URL` in `src/components/Hero.jsx`
- Timeline content: `src/components/Journey.jsx`
- Rules, FAQ, partners, footer: `src/components/Sections.jsx`
